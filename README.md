# design-critique

Get structured design feedback on usability, hierarchy and consistency from a Figma link, screenshot or mockup, at any stage from exploration to final polish.

This is an agent skill: `SKILL.md` tells an AI coding agent such as Claude Code when to use it and which steps to follow.

## Install

```bash
git clone https://github.com/alinvarat/skill-design-critique.git ~/.claude/skills/design-critique
```

Based on Anthropic's knowledge-work-plugins (Apache-2.0). Local modifications by alinvarat.
